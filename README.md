# NHS Scotland A&E Performance Analysis

## Overview
This project analyses weekly Accident & Emergency (A&E) activity and waiting times across Scotland using open data from NHS Scotland.

The objective is to assess whether the deterioration in waiting time performance is primarily driven by increasing demand or by structural constraints within the healthcare system.

---

## Key Question

**Is the decline in A&E performance explained by rising demand, or are there underlying structural issues affecting the system?**

---

## Objectives
- Analyse trends in A&E attendance volumes over time  
- Evaluate performance against key waiting time targets (4h, 8h, 12h)  
- Identify post-pandemic changes in system efficiency  
- Explore regional differences across Health Boards  

---

## Tools & Technologies
- Python  
- Pandas  
- Matplotlib  
- Jupyter Notebook  

---

## Key Findings
- A&E attendance volumes remained relatively stable over time.
- Since the COVID-19 pandemic, the percentage of patients seen within 4 hours has declined significantly.
- Delays exceeding 8 and 12 hours increased post-pandemic, indicating growing system strain.
- Significant regional disparities exist across Health Boards.

**Conclusion:**  
The decline in A&E performance is **not fully explained by demand**, and is consistent with **underlying structural constraints** such as capacity and resource limitations.
